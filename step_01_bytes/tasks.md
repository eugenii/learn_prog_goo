Его рейтинга (дробное число, 4 байта, формат 'f').

Задание:

1. Используя struct.pack, упакуй ID 42 и рейтинг 95.5 в одну переменную header.
2. Выведи длину получившегося объекта header (должно быть ровно 8 байт).
3. Представь, что ты "прочитал" этот заголовок. Используй struct.unpack, чтобы достать ID и рейтинг обратно из переменной header.
4. Сложный момент: Попробуй изменить ID в уже созданном header, превратив его сначала в bytearray. Замени любой байт внутри и посмотри, как изменится число при повторном unpack.

Зачем это нужно: Так работают форматы BMP, WAV и сетевые пакеты. Мы учимся видеть в наборе странных символов \x00\x0f реальные данные.

```python
#  пример:
import struct
# Упаковываем число 1024 в 2 байта (формат 'h')
data = struct.pack('h', 1024) 
print(data) # Увидишь b'\x00\x04' (зависит от порядка байтов)
```

Модуль struct позволяет превращать байты в привычные числа Python и обратно.

Основные символы формата:

i — целое число (int, 4 байта).

f — число с плавающей точкой (float, 4 байта).

h — короткое целое (short, 2 байта).

### 4 array.array

Мы подошли к вопросу эффективности. Обычный список в Python (list) очень «прожорлив», потому что хранит не сами числа, а ссылки на объекты. Если нам нужно хранить миллион целых чисел, list может занять 30-40 МБ, в то время как специализированный массив займёт всего 4 МБ.

Модуль array.array — это золотая середина между удобством списка и компактностью байтов.

```python
import array
# 'i' — это тип данных (signed int, 4 байта)
numbers = array.array('i', [1, 2, 3, 4, 5])
print(numbers.tobytes()) # Можно мгновенно превратить в байты
```

### Шаг 5: Профилирование и Memoryview (Финал курса)

Когда данных терабайты, даже копирование байтов из одной переменной в другую — это дорого. Для этого есть memoryview. Он позволяет смотреть на данные (срезать их, крутить), не копируя их в новую переменную.

Пример:
```python
large_data = bytearray(10**6) # 1 мегабайт
view = memoryview(large_data)
chunk = view[10:20] # Это НЕ копия, это просто "окно" в те же самые данные
```
Используйте код с осторожностью.
