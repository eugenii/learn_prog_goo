## 1. Итераторы: «Кто здесь следующий?»
Суть: Это объект, который выдает элементы по одному. 

Итерируемый объект (Iterable): Это «склад» (список, строка). 

У него есть метод __iter__, который возвращает итератор.

Итератор (Iterator): Это «кладовщик». Он помнит, где остановился, и имеет метод __next__.

Как это работает внутри:Когда ты пишешь for x in [1, 2, 3], Python делает следующее:Вызывает it = iter([1, 2, 3]) (получает «кладовщика»).Повторно вызывает next(it). 

Когда элементы кончаются, итератор выбрасывает исключение StopIteration, и цикл завершается.

#### Задание: Итератор «Прыгающая лягушка» (FrogJump)

Представь, что у тебя есть список данных, но тебе нужно пройтись по нему не по порядку, а с определённым шагом (например, через один или через два элемента).Твоя задача:Напиши класс-итератор FrogJump, который принимает список data и число step (шаг прыжка).

Требования:Итератор должен начинать с нулевого индекса.На каждой итерации он должен возвращать элемент и «прыгать» вперед на указанный step.Как только индекс выходит за пределы списка — остановка.Важно: Не используй срезы типа data[::step], напиши логику внутри __next__ через указатель (индекс).Пример работы:

```python
frog = FrogJump([10, 20, 30, 40, 50, 60], step=2)
for val in frog:
    print(val)
# Должно вывести:
# 10
# 30
# 50
```

## 2. Генераторы: «Ленивые вычисления»

Суть: Это упрощенный способ создания итераторов.

Вместо того чтобы создавать класс с методами __iter__ и __next__, ты пишешь функцию с ключевым словом yield.

Функция: Выполнилась и «умерла» (забыла локальные переменные).Генератор: Дошел до yield, отдал значение и «уснул», сохранив всё своё состояние.

Главный плюс: Экономия памяти. Генератор не хранит миллион чисел в списке, он знает, как вычислить следующее число, когда его попросят.

## 3. Декораторы: «Обертка для подарка»

Суть: Это функция, которая принимает другую функцию и расширяет её поведение, не меняя её код.
```python
def my_decorator(func):          # 1. Принимаем функцию
    def wrapper():               # 2. Создаем "обертку"
        print("До функции")
        func()                   # 3. Вызываем оригинал
        print("После функции")
    return wrapper               # 4. Возвращаем обертку
```
